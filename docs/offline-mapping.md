# Offline Android recording and reconstruction

`LiveCaptureService` accepts an explicit offline target. Its MediaProjection consent, foreground visibility, landscape/game-package filtering, native row-stride decoding and toolbar occlusion mask are shared with optional streaming. Offline mode commits a lossless PNG and its SHA-256, then metadata, then recording counters. One frame is in flight; busy samples are skipped instead of accumulating a RAM queue. Stop drains the capture callback and accepted disk write before finalizing. Incomplete pixel/metadata pairs are excluded. Less than 256 MB free space stops recording without discarding evidence.

Recordings are new namespaces in app-private `offline-recordings`. They are independent of the removed earlier phone mapper and of laptop data. Original PNGs remain immutable. JSON commits use fsynced temporary files and atomic replacement. App uninstall/clear-storage removes these recordings. Sharing is an explicit user-chosen ZIP with read-only URI grants; the provider cannot expose arbitrary files.

`OfflineMapService` is a user-started foreground data-processing job with progress and pause. A bounded wake lock permits processing while the screen sleeps. Android 15's data-sync time budget and vendor restrictions can interrupt work; originals and checkpoints survive. The UI recovers abandoned recording/processing states after a restart. Notification permission is optional; progress still appears in the app.

`OfflineReconstructor` uses the packaged OpenCV Android library. Native PNGs are analysed at no more than 960 pixels wide for SIFT. Masks exclude movement pads, known UI, the floating toolbar and saturated moving effects. Features and descriptors are cached on disk, with eight active feature/matcher sets in memory.

The first pass tracks nearby views. Robust affine fitting checks that apparent motion has approximately unit scale and no rotation; the actual constraint is the median translation converted back to native pixels. At least 18 matches, sufficient spatial spread and a 70 percent consistent-match ratio are required. Nearby extra constraints must agree with the primary path. Menu/gap boundaries interrupt local continuity.

The batch revisit pass searches the full recording, including future frames, using low-resolution scene signatures to shortlist distant candidates. It can recover across a capture gap, but a disconnected join needs two independent matching observations, stronger inlier evidence and no competitive conflicting placement. Within an existing component, loop constraints must agree with its approximate path. Cached matching checkpoints permit resume. The translation graph builds a maximum-confidence spanning forest, excludes conflicting non-tree edges, and robustly refines positions with component origins fixed. Unlinked components have no invented relative placement.

Rendering reads each original PNG once as a bitmap and rounds translations to integer native pixels. Exact HSV masks are built from 64-row strips; the full native distance transform is reduced to byte scores before painting. It chooses unchanged opaque source pixels according to distance from occlusions and frame edges, with the latest observation winning equal scores. There is no averaging, geometric scaling, texture brightening or pixel interpolation in exported tiles. Feature descriptors and matchers are released before this stage. Only one section's four 512 × 512 RGBA/quality tiles are cached. Tiles are flushed before each eight-frame checkpoint and the final frame; interruption replays at most seven uncheckpointed frames idempotently. Unchanged pixels avoid PNG rewrites; visibility-only improvements write just the quality sidecar.

The pan/zoom display uses a fitted preview capped at 1024 pixels on its longest side. Preview tiles are decoded with sampling, without loading their quality arrays; low memory falls back to 512 and 256 pixels. Failure to fit even the smallest preview records `previewAvailable=false` and leaves the completed native map exportable. The viewer bounds legacy-preview decoding to a small pixel budget. `NativePngWriter` exports one native RGBA row at a time into bounded compressed PNG chunks, retaining transparent gaps and using a lossless Sub filter. Temporary disk bands (at most 16 MB) prevent repeatedly decoding a tile for every output row; they are removed on completion or failure. No full-map bitmap is allocated. Export failure removes the incomplete newly chosen document when the provider permits it, reports failure and keeps original recording/tiles. Oversized PNG dimensions are rejected explicitly rather than silently resized.

This estimates the visible scenery map. Parallax, decorative foreground layers, repetitive textures, effects, missed views and incorrect registration can still prevent a faithful whole-level reconstruction. Processing time cannot restore unseen terrain. Recorded maps are not integrated into farmer navigation in this release.

The native Android integration fixture covers full-resolution images, reverse motion, a vertical drop, interrupted rendering and PNG source-pixel equality using the actual packaged library. Synthetic evidence is not a real-game accuracy guarantee.
