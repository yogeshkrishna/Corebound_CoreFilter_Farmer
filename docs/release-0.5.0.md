The mapper now streams original-size lossless game images directly to **Ceiling Scout Studio on your laptop**, where a map is built alongside your play. The old phone mapper, saved-map queue, preview overlay and ZIP sharing screens have been removed. Old private phone recordings are cleaned up when this update opens; laptop files are untouched.

Download and extract **Ceiling-Scout-Studio.zip**, then open **Start Studio.cmd**. In the updated phone app choose **Live laptop map**, pair with Studio's QR/link on the same Wi-Fi, and press **Start live capture**. Accept Android's screen-sharing prompt. The bar uses Stream/Stop; farming remains Run/Pause.

Studio retains native PNGs, timestamps, dimensions/orientation, masks, checksums and registration results. It offers pan/zoom, separate sections for uncertain tracking, native PNG export and observed border data. The link persists across switches/restarts; a changed laptop IP needs reconnection. Capture targets up to eight frames/second, with actual speed depending on encoding and Wi-Fi.

Native pixel scale does not guarantee complete or perfectly registered maps. This release needs a live phone trial. Laptop maps do not yet steer farming. Install over the old phone app to preserve build/calibration.
