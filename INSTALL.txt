CEILING SCOUT 0.5.0 — LIVE LAPTOP MAPPING

PHONE
1. Ceiling Scout > Check for updates > Download & install > confirm Install.
   Install over the old app to retain build and calibration.
2. Enable Ceiling Scout controls in Android Accessibility if disconnected.
3. Choose Live laptop map. Use the same Wi-Fi as the laptop.
4. Scan Studio's QR, or paste its connection link under Connect laptop.
5. Start live capture > accept Android screen sharing > play Corebound manually.
   Stream does not control the game. Stop on the bar ends capture.

LAPTOP
Extract Ceiling-Scout-Studio.zip. Double-click Start Studio.cmd.
First launch installs image tools. Python 3.12+ is required.
Keep Studio running. Pan/zoom and export native PNG or map data.
Originals and metadata stay in Documents\Ceiling Scout Live.
The link survives app switches/restarts; a changed laptop IP needs reconnection.
Weak matches create separate sections. Unseen pixels stay transparent.

FARMING
Choose Use farmer, open Lost Scrapyard with Frozen five stars, then Run.
Build, Calibrate and Stop & hide are under the three-dot menu.
Default: three Hookshots / seven jumps. Update your build in settings.
Laptop maps do not yet guide farming. Supervise the first runs.

The old phone archive mapper, Preview and ZIP transfer have been removed.
Old private phone recordings are removed when this update opens.
Old laptop recordings are never imported or deleted by this app.
This version needs a phone trial. Native scale is not guaranteed full coverage.
